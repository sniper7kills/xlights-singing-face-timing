How it works

  1. Add a song. The app draws the waveform.
  2. Transcribe. A speech model in your browser finds each word and its time. Paste the lyrics for better results.
  3. Check. Drag words into place. Watch the face preview sing.
  4. Export. Download an .xtiming file with one timing track for each voice.
  5. Import in xLights. Import Timing Track, then drop a Faces effect.
