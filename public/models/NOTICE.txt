Singer split model files of xLights Singing Face Timing
=========================================================

The option "Split the singers" of the app downloads one of these files from
this folder. The STFT is outside each model. The maintainer ruled on
2026-11-25 to ship the files with this attribution.


1. bs_roformer_male_female_aufr33.v2.w16.onnx

   Model:    BS-RoFormer male and female vocals model
   Author:   aufr33
   Source:   the model list of python-audio-separator 0.48.0,
             file bs_roformer_male_female_by_aufr33_sdr_7.2889.ckpt
             https://github.com/karaokenerds/python-audio-separator
   Licence:  The author states no licence.
   Copy:     A copy at huggingface.co/Politrees/UVR_resources has the
             tag "mit".
   Note:     This project converted the model from PyTorch to ONNX with
             float16 weights. The project did not train the model.
   Size:     266945164 bytes
   SHA-256:  da41d39969d2282c8bf1ce746f85fa01fb064666f1c0925b893d2447aaddd700
