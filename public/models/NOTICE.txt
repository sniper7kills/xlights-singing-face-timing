Singer split model files of xLights Singing Face Timing
=========================================================

The option "Split the singers" of the app downloads one of these files from
this folder. This project did not train the models. This project converted
each model from PyTorch to ONNX with float16 weights. The STFT is outside the
model. The maintainer ruled on 2026-11-25 to ship the files with this
attribution. The authors state no licence.
